# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | none                 | Maintainer needs to evaluate this issue  |
| `needs-info`               | none                 | Waiting on reporter for more information |
| `ready-for-agent`          | none                 | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | none                 | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table. No label exists in this repo for the four roles marked "none", so for those the skills apply no label.
